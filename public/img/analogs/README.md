# Fotos de los análogos

Dueño: C. Cada foto se referencia desde `analogs.image` como `img/analogs/<id>.jpg`.

## Reglas
- Nombre del archivo = id del análogo: `uyuni.jpg`, `rio-tinto.jpg`, …
- Formato JPG, unos 800 px de ancho, menos de 200 KB.
- Solo imágenes con licencia que permita usarlas: dominio público de NASA o Creative Commons (por ejemplo de Wikimedia Commons).
  Anota el autor y la licencia en la tabla de abajo.
- Cuando subas la foto, cambia `image` de `null` a `'img/analogs/<id>.jpg'` en `supabase/seed/02_analogs.sql`.
